# 作業・レビュー依頼

- run_id / task_id / request_revision:
- owner_role / owner_agent_id:
- shared_run_absolute_path / 作業ディレクトリ:
- 入力ファイル・対象依頼版:
- レビューの場合: 対象結果版・結果SHA256・作者ID:
- 開始条件・依存先と完了証跡:
- 目標・完了条件:
- 所有ファイル（この担当だけが変更）:
- 変更禁止範囲・既存変更:
- ブランチ/worktree/HEAD:
- 検証方法・出力先:
- 結果またはレビューの確定ファイル名:
- 未確認事項・制約・権限:
- 差し戻し時: 対応する指摘ID・前版との差・レビュー回数:
- 再開時: 旧担当の停止確認・新担当ID・残作業:

完成ファイルを公開後、通知はパスだけ。所有範囲外や不明点は質問ファイルで返す。
