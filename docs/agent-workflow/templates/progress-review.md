## Issueへの引き渡し

| 提案ID（改善・Skill両方） | 識別キー（run:確定レビュー名:提案ID） | Issue本文案のパス |
| ------------------------- | ------------------------------------- | ----------------- |
|                           |                                       |                   |

全提案についてissue-proposal.mdテンプレートで本文案を1件ずつ作成し、進行管理へ引き渡す。管理が重複確認・登録・読戻しを行い、登録記録とplan.mdにIssue URLを残す。

提案なしの場合は理由を記録し、Issueを作らない。採否・実施・効果は管理がplan.mdへ記録する。採用/保留/見送りはいずれも登録対象であり、Issue登録だけでSkill作成・インストール・設定変更を行わない。
